The pixiv embedded-browser callback regression requires a working QtWebEngine
runtime. It runs on the Windows release runner. The Linux workspace can skip
that one test when optional X11 runtime libraries are unavailable.

Release validation (pending for v0.4.15):
The Windows workflow runs full_test.py before packaging, then verifies the
frozen app, bundled gallery-dl, updater and stable launcher, installer creation,
clean install, two-step upgrade, old-version cleanup, rollback-version retention,
reinstall, installed-app self-test, uninstall, user-data preservation,
and SHA-256 generation. A GitHub Release is published only if every step passes.
Installed shortcut AppUserModelID and stable target, and a preserved shortcut
across two upgrades/reinstallation/version cleanup, are checked on the runner.
The machine-readable result ships beside each installer as release-check.json.

Real X/pixiv credentials are intentionally not present in automated tests.
Live X/pixiv account collection was not exercised in this validation.
Explorer taskbar pin/unpin interaction was not automated; the Windows Shell
properties, stable shortcut target and installation/update paths are verified.
